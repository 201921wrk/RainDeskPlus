# Visual Studio 2026 安装勾选清单

> 针对 RainDeskPlus 项目（C++17, MSVC v145, Direct2D, Rainmeter 源码构建）的具体勾选指南。

## 步骤一：工作负荷（Workloads）

**核心必选工作负荷**：
- [x] **使用 C++ 的桌面开发** (Desktop development with C++)
  - ⚠️ **这是最关键的一步！** 勾选后，右侧会列出自动包含的单个组件，**核心的编译器工具集就是随这个工作负荷自动安装的**，不会在单个组件列表中独立列出！

## 步骤二：单个组件（Individual Components）

**如果您已勾选「使用 C++ 的桌面开发」工作负荷，请直接跳到步骤三确认安装即可**，因为核心编译器已经自动勾上了。

如果您想手动确认编译器是否已被选中，请按以下步骤查找：

1. 切换到「单个组件」选项卡。
2. **不要**在搜索框中输入 "MSVC"，因为编译器可能不在 "SDK、库和框架" 分类下。
3. **向下滚动列表**，查找名为 **"编译器" (Compilers)** 的分类或组件。
4. 在编译器分类下，查找并勾选：
   - [x] **MSVC v145 - VS 2026 C++ x64/x86 生成工具** (或显示为 "Microsoft Visual C++ 14.51 tools for x64/x86")
   
   *提示：这通常位于整个组件列表的最下方区域。*

## 步骤三：最终确认（建议操作）

因为核心编译器随工作负荷自动提供，最稳妥的方式是：

1. 在 VS Installer 左侧，确保勾选了 **「使用 C++ 的桌面开发」**。
2. 在右侧的 "安装详细信息" 面板中，查看 "使用 C++ 的桌面开发" 下方的 "单项可选" 和 "单个组件"，您应该能看到以下关键组件已被自动选中：
   - [x] **MSVC v145 - VS 2026 C++ x64/x86 生成工具** (核心编译器)
   - [x] **Windows 11 SDK (10.0.22621.0)** 或 **Windows 10 SDK (10.0.19041.0)**
   - [x] **C++ CMake 工具**
3. （可选）在单个组件中额外勾选：
   - [ ] **Git for Windows** (如未安装)
   - [ ] **C++ MFC** (如果需要)
   - [ ] **C++ 调试器**

## 步骤四：安装

点击「安装」或「下载时安装」。

## 总结

- **核心编译器 (MSVC v145)** 是随 **「使用 C++ 的桌面开发」** 工作负荷**自动安装**的，您不需要单独在组件列表中勾选它。
- 您在截图中看到的 "C++ ATL for x64/x86 (MSVC v14.51)" 和 "C++ MFC for x64/x86 (MSVC v14.51)" 已经确认了 v145 工具集的相关库是可用的。
- 只要工作负荷勾选正确，核心工具链就会就位。
